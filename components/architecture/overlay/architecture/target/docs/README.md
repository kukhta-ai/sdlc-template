# Arc42 starter

The numbered files under `src/` are a locally adapted version of the official Arc42 9.0 English plain
AsciiDoc template. Structurizr Local renders them as the target system's documentation.

Source revision, attribution, modifications, and license terms are recorded in
[`../../UPSTREAM.md`](../../UPSTREAM.md) and
[`../../licenses/ARC42-CC-BY-SA-4.0.txt`](../../licenses/ARC42-CC-BY-SA-4.0.txt).

Fill only the sections that help the team understand or verify the system. Delete obsolete placeholders as
real content replaces them; do not invent facts merely to complete the template.
