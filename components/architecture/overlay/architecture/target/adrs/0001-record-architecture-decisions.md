# 1. Record architecture decisions

Date: 2026-08-10

## Status

Accepted

## Context

We need to preserve the reasoning behind consequential architecture choices for __PROJECT_NAME__.

## Decision

We will record those choices as lightweight Architecture Decision Records beside the target model.

## Consequences

The project gains an auditable decision history. Each later ADR should state the forces, chosen option,
tradeoffs, and follow-up work without restating the model or Arc42 documentation.
